# flagstone assets

| File | What it is |
|---|---|
| `pickup.wav` | A placeholder pickup cue: a 0.1 s rising blip (22.05 kHz, mono, 16-bit). |

## Origin

`pickup.wav` is generated by `tools/make_pickup.py` (Python standard library only). It is
built from arithmetic in that script: no third-party sample or recording is used or derived
from. Regenerate it with:

```bash
python3 -I flagstone/assets/tools/make_pickup.py
```

The output is deterministic, so a rerun with an unchanged script leaves the file unchanged.
