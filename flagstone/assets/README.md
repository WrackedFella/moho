# flagstone assets

| File | What it is |
|---|---|
| `pickup.wav` | A placeholder pickup cue: a 0.1 s rising blip (22.05 kHz, mono, 16-bit). |
| `mark.wav` | A placeholder cue for marking a block for mining: a 0.1 s rising blip (520 to 780 Hz, same format). |
| `unmark.wav` | A placeholder cue for cancelling a mark: the same blip falling (780 to 520 Hz). |

## Origin

`mark.wav` and `unmark.wav` use the same envelope and format as `pickup.wav` with other
pitch ranges. They were generated by a one-off program from arithmetic alone; nothing third-party
is used or derived from.

`pickup.wav` is generated by `tools/make_pickup.py` (Python standard library only). It is
built from arithmetic in that script: no third-party sample or recording is used or derived
from. Regenerate it with:

```bash
python3 -I flagstone/assets/tools/make_pickup.py
```

The output is deterministic, so a rerun with an unchanged script leaves the file unchanged.
